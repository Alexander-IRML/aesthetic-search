# ArtSearch v0.5.0

Release date: 2026-08-26

## Closed-Alpha Milestone

v0.5.0 turns the local retrieval workbench into a complete invite-only cloud
search path. A tester can upload one artwork in a browser, receive ten similar
approved corpus images, inspect artist/source attribution and component scores,
and grade every result without sending query traffic through the developer
laptop.

The deployed request path is:

```text
Cloudflare Worker access gate
  -> scale-to-zero Cloudflare CPU Container
  -> pinned CLIP subject + CSD style query encoder
  -> Qdrant named-vector recall and reciprocal-rank fusion
  -> Neon PostgreSQL catalog and product telemetry
  -> private R2 media through the Worker
```

## Retrieval Contract

- CLIP `openai/clip-vit-base-patch32` represents subject and semantic content.
- Contrastive Style Descriptor `yuxi-liu-wired/CSD` represents artistic style.
- Both models are pinned to immutable revisions and baked into the query image.
- Qdrant searches the two named vector spaces independently and fuses their
  ranked lists with reciprocal-rank fusion.
- The active physical collection contains 8,279 approved artworks and is read
  through the stable `artworks_active` alias.
- The old DINO pooled and patch vectors are no longer part of active serving.

Every successful response reports the model-bundle hash, active index alias,
component scores and ranks, query ID, session ID, and latency breakdown.

## Data And Operations

- PostgreSQL is the canonical cloud metadata, model-lineage, workflow, and
  telemetry store. SQLite remains the resumable worker-local intake database.
- Alembic manages PostgreSQL schema evolution through migration
  `20260823_0003`.
- A transactional outbox publishes committed PostgreSQL corpus changes to
  Qdrant and detects count or payload drift.
- Accepted source objects are content-addressed in R2. Rejected image bytes are
  not uploaded by the production publisher.
- Airflow, Polars, Spark, HTTPX, and S3-compatible publication remain available
  for scheduled intake, manifests, reconciliation, and throughput reporting.
- Daily and bulk launchers preserve roster rotation, actor cursors, run
  checkpoints, retry evidence, and caller ordering.

## Alpha Product

The public surface intentionally remains small:

- one in-memory JPEG, PNG, or WebP upload, capped by bytes and decoded pixels;
- ten CLIP/CSD fused results with at most two results from one artist;
- source attribution and private same-origin R2 image delivery;
- Great, Good, and Bad result judgments;
- stable JSON errors, request IDs, liveness, and model/index readiness.

The operations dashboard aggregates search totals, success and failure rates,
p50/p95 latency, feedback coverage, judged hit rate, Precision@10, nDCG@10,
Qdrant Recall@100, intake throughput, filter quality, drift, and model/index
lineage. Precision@10 and nDCG@10 are measured only after all ten displayed
results have judgments. Recall@100 is exact-versus-HNSW ANN recall, not an
estimate of all semantically relevant corpus items.

## Cloud Boundary

- The Worker requires a high-entropy alpha access code and issues a signed,
  HttpOnly, Secure, SameSite=Lax session cookie.
- Authentication is checked before the paid Container can wake.
- The deployment permits one 1-vCPU, 4-GiB Container and sleeps it after 15
  idle minutes.
- Qdrant, PostgreSQL, and session secrets are Cloudflare-managed runtime
  secrets. They are not baked into the image or repository.
- R2 objects are read through a narrow binding and are not anonymously public.
- Query uploads are decoded in memory and are not retained.

## Known Alpha Limits

- One CPU inference owner means simultaneous searches queue briefly or receive a
  busy response. Warm end-to-end search latency is currently around 15 seconds.
- The shared alpha code cannot identify or revoke one tester independently.
- Provider spend alerts, external uptime paging, and CI deployment automation
  remain operator setup work.
- Artist opt-out, upstream deletion propagation, and result reporting still
  require a documented operator procedure before a wider release.
- The hosted query path is live, but unattended cloud corpus refresh is not yet
  the default; the current intake scheduler remains operator-controlled.
- Classification and inclusion do not establish attribution, copyright
  permission, safety, or consent, and do not override artist opt-outs.

These constraints are acceptable for a small trusted alpha and are explicit
promotion gates for broader access.
